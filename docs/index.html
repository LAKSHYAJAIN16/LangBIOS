Talk to your BIOS in plain English.

LangBIOS is a natural-language interface to real BIOS/UEFI firmware settings, not a simulation. It reads and writes actual firmware state through the same OS-mediated mechanisms enterprise tools use, on both Windows and Linux.

Read the docs View on GitHub 
langbios> enable secure boot
secure_boot is read-only from software: the firmware
deliberately doesn't allow OS-level writes to it.
langbios> what's my fan profile
No real BIOS attribute on this machine matches 'fan_profile'...
langbios> list settings

Real firmware, not a mock

Every read and write goes through the actual UEFI runtime services or a vendor's BIOS management driver. Nothing is simulated.

Windows & Linux

Win32 firmware APIs + WMI on Windows; efivarfs + the kernel's unified firmware-attributes sysfs ABI on Linux.

Honest about limits

Secure Boot and TPM are read-only everywhere, by firmware design. Vendor settings only work where the OEM built the interface, and this tool says so plainly instead of faking success.

Rules first, LLM as fallback

A fast local rule parser handles common phrasing; an optional local LLM (via Ollama, no API keys, no cloud) picks up anything it misses.
